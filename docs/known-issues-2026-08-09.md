## 1. ~~已有原文字幕 + 开启翻译 + 不覆盖 → 整个任务跳过,连翻译也不做~~ 已修复

**修复(2026-09-04)**:`job::run_batch` 现在把"已有原文字幕"的判定抽成纯函数
`decide_existing_srt`(见 `src/job.rs`)——开翻译时返回 `UseExisting`,直接用已存在的
`Video.srt` 当翻译输入产出 `Video.zh.srt`,不再整任务跳过;不开翻译时才整任务跳过。
已有原文 + 开翻译但语言未知(没跑 whisper)时,警告文案改为"未重新识别视频,无法确定源
语言",不再误导用户以为跑过识别。已加单测覆盖三种路径(跳过 / 用已有原文 / 正常流水线)。

**原问题描述**:

真实行为(读代码确认,非回归,我的 "跳过判定提前" 改动前后行为一致):

用户已经有 `Video.srt`(比如上一季没开翻译跑出来的),现在勾选"翻译成中文",
`overwrite_existing = false`(默认)。点"开始处理":

1. `job::run_batch` 在开工前用 `existing_srt_skip_reason` 判定 `Video.srt` 已存在
   → 任务直接标记为 `Skipped("已有同名字幕,未覆盖(...)")`。
2. 翻译阶段根本没有机会运行,用户拿不到 `Video.zh.srt`。

**为什么这是问题**:用户的意图是"我已经有字幕了,只想让它被翻译成中文",但得到的是
"跳过: 已有同名字幕",而且这行文案完全没解释"因为原文被跳过,所以翻译也没做"——
用户会以为翻译功能坏了,或者干脆没意识到要先把原文删掉/改覆盖设置。

**为什么当时暂不处理**:

- 修复方向不是改文案,而是改流程:跳过原文字幕时,应该直接拿**已存在的** `Video.srt`
  当输入跑翻译(不需要重新跑 ffmpeg/whisper,反正原文已经有了)。这要求把 `run_batch`
  里"process_video → place_sidecar_srt → translate"这条线性流程改成可分支的,`placed`
  的来源有两种(新生成的 / 已存在的),并且跳过原文字幕时仍然要把已存在的原文路径传给
  translate 阶段。
- 这个分支会引入一个新的"结果来源"状态(`detected_language`/`subtitle_count`/`reused_srt`
  等 report 字段在"没跑 process_video"时怎么填),需要额外设计,不是几行的事。
- 翻译相关的任何流程改动,按项目纪律都要拿真实模型跑一遍确认没引入质量回归
  (见 README TODO 里"翻译跨批上下文携带"的同款要求)。当前没有真实模型环境可验证。

## 4. 模型清单窗口每帧递归扫描存放目录(潜在性能问题,非正确性 bug)

**真实行为**(读代码确认):`ui/model_manifest.rs` 的 `collect_rows()` 在窗口打开期间
**每帧**调用 `setup::status_for` → `paths::model_path`/`vad_model_path`/`trans_model_path`,
而这些函数在没有绑定表命中时,会对整个 `models_dir()` 做一次**递归文件搜索**
(`find_all_matching_files`)。模型清单里有 6 行(3 个 whisper 档位 + VAD + 2 个翻译模型),
等于窗口开着的时候每帧最多做 6 次全目录递归遍历。

**为什么是问题**:`models_dir()` 可能指向用户自己的 HF 缓存(几千个文件的嵌套结构,README
文档化了这个用法)。这种目录下每帧 6 次递归扫描会拖慢界面(下拉/滚动/任何交互触发重绘时
都重扫)。这是第 4 轮走查发现的,不是回归。

**为什么暂不处理**:

- 修法需要给模型状态加缓存(文件大小/存在性会随下载/清理变化,缓存要带失效条件,比如
  "本轮有后台模型操作时强制重查"),复杂度明显超过"这是个小毛病"的量级,而且模型清单
  是低频打开的辅助窗口,不是主界面常驻面板。
- 想彻底解决应该让 `status_for` 接受"已解析路径"而不是自己再去搜(路径解析和状态判定
  分离),但那会改动 `status_for` 的调用面(`setup::missing_components`/首次下载页也在用)。

**如果以后要修**:给 `models/` 加一层"模型状态缓存 + 失效标记"或者把 `resolve_in_store`
的结果缓存起来,在 `pending_verify`/`inline_install`/`pending_cleanup`/`scan` 任一活动时
跳过缓存强制重查。
